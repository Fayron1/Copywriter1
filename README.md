# Copywriter1 — Мультиагентная ИИ-Редакция для B2B

Интеллектуальная система автоматизации создания премиального B2B-контента: юридически точные статьи журнального качества по русскому праву, налогам, закупкам (44-ФЗ/223-ФЗ), маркетплейсам и B2B-маркетингу.

Конвейер из 9 специализированных ИИ-агентов + слой детерминированной верификации: инвариантная математика, гибридный векторный поиск, перекрёстные линтеры правовых норм и автофикс-гейт перед публикацией.

Проект работает и развивается под управлением **Antigravity**.

---

## 🤖 Архитектура ИИ-Редакции

1. **🧠 The Brain (Оркестратор):** декомпозирует тему, составляет ТЗ, управляет пайплайном.
2. **🔎 The Fact-Finder (Исследователь):** гибридный поиск (dense e5 + sparse BM25-стиль, RRF) по базе знаний в Qdrant — законы, снимки норм, письма ведомств, оферты площадок.
3. **📡 The Scout (Разведчик):** свежие тренды через SearXNG и Vane (локальный Perplexity-движок с цитатами [1][2][3]).
4. **🏗️ The Engineer (Структурировщик):** асимметричный Blueprint, ломающий ИИ-шаблоны.
5. **❤️ The Heart (Писатель):** плотный B2B-текст с эпистемическим статусом (факт vs прогноз vs проект).
6. **👮 The Sheriff (Редактор-Фактчекер):** аудит цифр против claim-pack, чистка ИИ-металексики.
7. **🪞 The Mirror (Стилист):** human-score, вариативность ритма, борьба с NPC-шаблонами.
8. **🚀 The Booster (SEO/GEO):** LSI-ключи, мета-данные (с гвардом фантомных ключей).
9. **🎨 The Artist (Визуализатор):** обложка и иллюстрации разделов.

## 🛡️ Слой детерминированной верификации (то, что отличает от «просто GPT»)

- **Калькуляторы вместо LLM-арифметики:** налоги (УСН/ОСНО/НДС с трассировкой), юнит-экономика маркетплейсов (P&L SKU), обеспечений по 44-ФЗ (заявка/ОИК/антидемпинг), пени и штрафы (ПП № 1042). Числа попадают в статью дословно из калькулятора.
- **Финальный гейт `autofix_gate`:** автофикс известных классов ошибок (устаревшие сроки, повреждённые токены вида «22 НМЦК», оговорки неуверенности) + блокировка публикации при оставшихся 🔴. С per-article `gate_markers.json` (PATCH_NOT_APPLIED).
- **~40 линтеров правовых норм:** старые редакции сроков, смешение 44/223-ФЗ, контаминация соседних норм (59-ФЗ → срок жалобы), практика ФАС как норма, будущие даты как действующие, потерянные единицы измерения, гарантированные исходы.
- **Паспорт статьи:** claim ledger, high-risk claims, источники с приоритетами, `as_of_date`, профиль процедуры.
- **163+ регрессионных теста:** каждый класс когда-либо найденной ошибки навсегда закрыт тестом.
- **Гибридный поиск:** dense (мультиязычный e5, локально) + sparse (hash-BM25) с RRF-слиянием — точные номера статей больше не размываются смысловой близостью.
- **Автофикс-цикл ревью:** точечные замены из редакторских ревью конвертируются в автофиксы и применяются ко всем файлам пакета (md/html/txt) без перегенерации.

## 🚀 Запуск

```bash
pip install -r scripts/requirements.txt

# .env: ключи DeepSeek/KIE, QDRANT_API_KEY, TELEGRAM_BOT_TOKEN, VANE_URL
python scripts/generate.py "Тема статьи" --dir "закупки" -t law_review --chars 8000
```

Направления (`--dir`): `налоги / закупки / маркетинг / трудовое / защита данных / вэд`. Типы структур (`-t`): `law_review, analysis, checklist, case_study, reference, seo`.

Регрессия: `python scripts/kb2/regression_tests.py` (163/163).

## ⚖️ Правила качества

- **Эпистемический фильтр:** прогнозы и планы ведомств — только как сценарии.
- **Первоисточник обязателен:** каждая цифра — статья закона + дата снимка; калькуляторы — только по нормам из первоисточников.
- **Ред-гейт:** юридические домены публикуются через claim ledger, линтеры и экспертный чек-лист; 🔴-замечания блокируют отправку.
