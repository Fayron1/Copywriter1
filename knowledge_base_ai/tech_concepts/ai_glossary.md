# AI-автоматизация для бизнеса: глоссарий и концепции

## RAG (Retrieval-Augmented Generation)
- Архитектура: база знаний → векторный поиск → LLM генерирует ответ на основе найденного
- Ключевое отличие от ChatGPT: отвечает ТОЛЬКО из вашей базы, не из интернета
- Компоненты: векторная БД (Qdrant, Chroma), embedding-модель, LLM, реранкер
- Ошибки внедрения: нет чанкинга, нет метаданных, нет фильтра актуальности
- Для бизнеса: AI-ассистент на ваших документах, который не галлюцинирует

## Мультиагентные системы
- Несколько специализированных агентов вместо одного «универсального»
- Роли: исследователь, писатель, редактор, факт-чекер, SEO-оптимизатор
- Преимущество: каждый агент лучше своей задачи, качество выше
- Риск: агенты могут подтверждать одну неверную рамку — нужен Red Team

## Vector Database
- Хранит документы как векторы (числовые представления смысла)
- Поиск по смыслу, не по ключевым словам
- Популярные: Qdrant, Pinecone, Weaviate, Chroma
- Для бизнеса: «умный поиск» по регламентам, договорам, кейсам

## Embedding
- Преобразование текста в вектор (набор чисел), где похожие тексты → похожие векторы
- Модели: OpenAI text-embedding-3, локальные e5, BGE-M3
- Для бизнеса: семантический поиск, кластеризация документов, дедупликация

## Hallucination (галлюцинация)
- LLM генерирует правдоподобный, но ложный факт
- Причина: модель не «знает», а «предсказывает следующее слово»
- Решение: RAG (ответ только из базы), факт-чек, линтеры, Red Team аудит

## Guardrails
- Правила и фильтры, ограничивающие поведение LLM
- Типы: запрет тем, формат ответа, проверка фактов, блокировка псевдо-экспертизы
- Для бизнеса: «AI не выдумывает цифры, не даёт юридических советов, не пишет от первого лица»

## Workflow Automation (Make, n8n, Zapier)
- Визуальные платформы для связи сервисов без кода
- Триггер → Действие → Результат
- Для бизнеса: автопостинг, уведомления, синхронизация CRM, обработка заявок

## AI Content Pipeline
- Конвейер превращения экспертных данных в контент
- Схема: база знаний → генерация → редактура → факт-чек → SEO → публикация
- Для бизнеса: «загрузите презентации → получите статьи, FAQ, посты, кейсы»

## Telegram Bot с RAG
- Бот, подключённый к векторной базе знаний автора
- Отвечает подписчикам в tone-of-voice автора 24/7
- Квалифицирует лидов на консультацию
- Для экспертов: «цифровой двойник» для первичных вопросов

## Evaluation (оценка качества AI)
- Измерение качества генерации: релевантность, точность, полнота
- Метрики: faithfulness (верность источнику), relevance, coherence
- Инструменты: RAGAS, DeepEval, SelfCheckGPT
- Для бизнеса: «как понять, что AI-ассистент отвечает правильно»

## Prompt Engineering
- Искусство формулирования запросов к LLM
- Ключевые приёмы: few-shot примеры, chain-of-thought, структурированный вывод
- Для бизнеса: правильный промпт = 80% качества результата

## Cost Optimization
- Кэширование промптов (DeepSeek: кэш-попадания в 10 раз дешевле)
- Выбор модели по задаче (Flash для классификации, Pro для генерации)
- Локальные модели (e5 для эмбеддингов = ноль затрат)
- Для бизнеса: одна статья 8k знаков ≈ 10–30 центов на DeepSeek
