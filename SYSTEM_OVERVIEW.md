# Copywriter1 — система производства экспертных B2B-статей

Мультиагентный конвейер, который пишет экспертные статьи по четырём доменам
(налоги, трудовое право, защита данных / 152-ФЗ, маркетинг) на собственной
базе знаний, с многослойным контролем фактов и готовой коммерческой упаковкой.

**Принцип: не «сгенерировать и проверить», а «ограничить и сгенерировать».**
Писатель получает только проверенные факты; всё, что не подтверждено,
отсекается до генерации, а не после.

---

## 1. Конвейер генерации (scripts/agents/pipeline.py)

Статья проходит ~20 этапов. Ключевые:

| Этап | Что делает |
|---|---|
| **Brain** | Анализ темы, выбор угла |
| **Fact-Finder** | Сбор фактов из БЗ (RAG) + внешний брифинг (Vane/SearXNG), маркировка primary/secondary |
| **Claim Ledger** | Извлечение атомарных утверждений → claim pack (только supported). Heart пишет строго из pack |
| **NormParams Passport** | Годовые параметры темы (ставки, лимиты, сроки) + матрица сценариев. Устаревшие значения — в чёрный список |
| **Engineer** | Blueprint статьи (структура разделов) |
| **Heart** | Написание текста. Цепочка моделей с фейловером (HEART_MODEL_CHAIN) |
| **Quality Edit Loop** | Шериф/Зеркало + внешний ревизор (Gemini) + **Red Team** (adversarial-аудит «докажи, что публиковать нельзя») |
| **Booster** | SEO/GEO-слой: LSI, мета, Citation Bait |
| **Statistical Humanizer** | Точечная гуманизация секций (human-score) |
| **References** | Сборка блока источников (2–5 ссылок, дедуп по доменам, фильтр redirect-URL) |
| **Deliverables** | Контент-пакет поставки + CTA-блок (см. раздел 4) |

Для налоговых тем дополнительно работает **детерминированный калькулятор**
(УСН 5/7/22%, ОСНО, прогрессивный НДФЛ по brackets) — расчёты кодом, не LLM,
с полной трассировкой «Выручка → Налоговая база → Налог».

## 2. База знаний (scripts/kb2/, scripts/copywriter_kb/)

- **Qdrant** (VPS, коллекция `kb_v2`, ~80k чанков), локальные эмбеддинги **e5** (768d, без OpenAI)
- **182 исходника** (~764 МБ): кодексы и ФЗ (2026 редакции), судебная практика,
  книги по маркетингу/копирайтингу/методологии, справочники
- Идемпотентные **uuid5** point-ID — перезалив не создаёт дублей
- `--fresh` перед сносом коллекции автоматически создаёт **снапшот**
- **Пополнение через Telegram-бота**: файл → авто-чанкинг → Qdrant; ежедневный
  watcher следит за изменениями норм (Vane/Yandex)
- Специализированные документы-матрицы (пример: подписная матрица КЭДО по
  ст. 22.1–22.3 vs 312.1–312.3 ТК РФ) закрывают известные факто-дыры

## 3. Контроль качества (scripts/agents/norm_params.py)

**48 регрессионных тестов** (`scripts/kb2/regression_tests.py`) — каждый класс
ошибок, когда-либо найденный редактором, воспроизведён тестом. Правила:

- Устаревшие значения (20%→22%, пороги НДС/УСН) — принудительная замена с
  защитой годов (замена голых чисел только как самостоятельного токена)
- Псевдо-экспертиза («на моей практике как юриста»), промпт-лики, обрывы текста
- Кейсы без маркировки «Условный пример», прогнозы-как-факты
- Подписная матрица КЭДО (запрет «работник подписывает только УКЭП»)
- Юридическая этика (маскировка трудовых отношений при ГПХ — 🔴)
- Внутренние контроли не выдаются за нормы закона
- Коммерческие абсолюты («лучший», «гарантируем»), бенчмарки и рыночные цифры
  без источника, доменный файрвол (налоговое не едет в маркетинговые статьи)

## 4. Коммерческий слой

- **CTA Renderer** (`cta_renderer.py`) — детерминированный, кодом (не LLM):
  5 шаблонов по сферам, вклейка после «Источников», режимы `self_promo` /
  `editorial` (CTA_MODE). Промо проходит те же линтеры, что и статья
- **Deliverables Renderer** (`deliverables.py`) + агент **Packager** (дешёвая
  модель): seo_title, meta_description, FAQ, 3 Telegram-поста, анонс,
  **паспорт источников** (approved claims, допущения, оговорка о финальной
  приёмке экспертом клиента) → `content_package.md` к каждой статье
- **Темы**: генератор → экспандер (210 тем, 7 формул × 16 сидов) →
  **ранжировщик** (`topic_ranker.py`): KB-опора (Qdrant) + виральность + спрос
  → шорт-лист top-30, вердикты ready/weak
- **Virality Engine** — 6 B2B-критериев заголовков (боль, миф, вопрос-хук,
  цифра, дедлайн, трансформация), выбор заголовка в 3 уровня

## 5. Инфраструктура

- **VPS**: Qdrant (localhost:6333, API-key), SearXNG, Vane (метапоиск),
  демон `kb-update` (приём файлов, запуск генерации, доставка статей в бот)
- **Telegram-бот**: загрузка документов в БЗ, команда генерации, статья
  приходит архивом (md + html + контент-пакет)
- **Запуск**: `python scripts/generate.py "Тема" --dir налоги --output DIR`
- **Модели**: DeepSeek (основной провайдер), Gemini (внешний ревизор),
  цепочка фейловера для Heart; Jev-роутер с фолбэком на LLM

## 6. Файловая карта

```
scripts/
  agents/          — пайплайн и агенты (pipeline, prompts_*, norm_params,
                     claim_ledger, tax_calculator, virality_engine,
                     cta_renderer, deliverables, rag, registry)
  kb2/             — БЗ и инструменты (loader, kb_update, topic_*,
                     regression_tests, upload_kb_corpus, kb_watchdog)
  copywriter_kb/   — конфиг и загрузчик Qdrant
knowledge_base/    — исходники (legislation / business / craft / style_client)
topics_*.json/md   — пул тем и ранжирование
```

## 7. Продуктовая логика

Система продаётся как лестница: **статья → контент-пакет → серия →
база знаний клиента → AI-редакция под ключ**. Первичный клин — бухгалтерские
аутсорсеры, 1С-франчайзи, HR/юруслуги, веб-студии (152-ФЗ): у системы уже
готова профильная БЗ по их тематикам. Позиционирование: «экспертные материалы
на специализированной базе источников, с паспортом фактов; финальную приёмку
правовых выводов делает эксперт клиента».
